# Astromaximum (JavaME)

Astromaximum is an astrological calendar for JavaME-enabled mobile devices. Originally developed in 2006, this lightweight midlet provides daily planetary events and interpretations for over 700 global locations.

## 🌟 Features
- Precomputed astrological data (planetary transits, moon phases, retrogrades, etc.) for 700 cities worldwide
- Textual interpretations of astrological events
- Built-in event database with annual updates
- Offline functionality — no network access required
- Compact design for legacy mobile devices

## 📱 Target Devices
- JavaME feature phones supporting MIDP 2.0 and CLDC 1.1

## 🔧 Build & Install
1. Compile using any JavaME-compatible toolkit (e.g., Sun Wireless Toolkit, J2ME Polish)
2. Generate `.jad` and `.jar` files
3. Transfer to device via Bluetooth, USB, or OTA
